> 这是 Webnovel Writer v8 内置的版本化规则包，不是番茄官方规则的复制品，也不替代番茄后台的投稿页面或审核结果。

## 身份

| 字段 | 值 |
| --- | --- |
| 规则包 id | `fanqie-short-story` |
| 版本 | `1` |
| 平台 | `fanqie` |
| profile | `fanqie-short-story` |
| 核对日期 | `2026-09-25` |
| 适用范围 | 番茄短故事通用创作与本地交付 |

规则包内容会计算 SHA-256，并把 hash 写入 `故事.json`、审读记录和交付检查。规则包内容或版本发生变化时，必须提升版本并重新核对来源；不能用同一个版本号悄悄改规则。

## 已记录的公开口径

当前内置的超短/中短目标范围来自番茄短故事 2026 年第二期「千字万金」公开说明：

- 超短篇：`8000—24900` 字；
- 中短篇：`25000—80000` 字；
- 字数口径：Unicode 码点；
- 这些是活动公开分类口径，不等于所有未来活动都永久采用。

## 创作与审读 guidance

规则包把官方公开的创作方向作为审读指导，而不是机械合规门槛：

- 开篇尽快建立具体危机或强冲突；
- 主角有清晰行动和选择；
- 冲突升级带来新的代价、选择或信息；
- 高潮回收前文铺垫，结局完成关系/价值/人物秩序收束；
- 用生活细节、关系、规则和具体场景承载矛盾。

全篇审读固定为三个模块：

1. 结构与因果；
2. 人物与情绪；
3. 连续性与交付。

## 交付边界

- 导出格式：Markdown、TXT；
- 不生成卷号或章号；
- 不自动发布、不代替作者投稿；
- 不把活动奖励口径当作永久规则；
- 交付检查会报告字数、未完成占位符和重复段落；
- 抄袭、异常引流、恶意水字数和章节重复属于人工/平台审核风险，不能由本地脚本冒充自动判定。
